## 1. Map 语义

### 定义

Map（映射）是 TLL 的内置关联数据结构，存储键值对。键必须是字符串类型，值可以是任意类型。Map 是引用类型。

### 创建

Map 通过字面量 `{ key: value, ... }` 创建。键可以是标识符或字符串字面量，编译器内部统一转换为字符串。

**正确示例：**
```tll
// 标识符键（推荐）
let user = { name: "TLL", age: 1 }

// 字符串字面量键
let config = { "host": "localhost", "port": 8080 }

// 空 Map
let empty = {}

// 嵌套 Map
let nested = { outer: { inner: 42 } }
```

**错误示例：**
```tll
// 错误：键不能是数字字面量
let m = { 1: "one" }  // Parse Error

// 错误：Map 字面量中键名不能与同名变量产生歧义
// （实现约束：键名与作用域内变量同名时行为未定义，应避免）
let key = "name"
let m = { key: "value" }  // 不推荐，键为 "key" 而非变量 key 的值
```

### 访问

Map 的值通过 Member 访问 `map.key` 或 Index 访问 `map["key"]` 获取。推荐使用 Member 访问。

**正确示例：**
```tll
let user = { name: "TLL", age: 1 }
io.println(user.name)      // "TLL"
io.println(user["age"])    // 1
```

### 修改

Map 的值通过 Member Set `map.key = value` 修改。Index Set `map["key"] = value` 在 v1.0 中**不保证可用**，应使用 Member Set。

**正确示例：**
```tll
let user = { name: "TLL", age: 1 }
user.name = "TLL v1.0"     // ✅ Member Set
user.age = 2                // ✅ 新增字段
```

**错误示例：**
```tll
let user = { name: "TLL" }
user["name"] = "New"        // ❌ Index Set 不保证可用
```

### 遍历

Map 遍历通过标准库函数实现（v1.0 暂不支持 `for key in map` 语法）。

## 2. List 语义

### 定义

List（列表）是 TLL 的内置有序序列数据结构，元素可以是任意类型，支持动态扩容。List 是引用类型。

### 创建

List 通过字面量 `[elem1, elem2, ...]` 创建。

**正确示例：**
```tll
let nums = [1, 2, 3, 4, 5]
let mixed = [1, "hello", true, null]
let empty: list = []
let nested = [[1, 2], [3, 4]]
```

### 访问

List 元素通过 Index 访问 `list[index]` 获取，索引从 0 开始。

**正确示例：**
```tll
let nums = [10, 20, 30]
io.println(nums[0])   // 10
io.println(nums[2])   // 30
```

**错误示例：**
```tll
let nums = [10, 20, 30]
io.println(nums[5])    // Runtime Error: index out of bounds
io.println(nums[-1])   // Runtime Error: negative index not supported
```

### 修改

List 元素通过 Index Set `list[index] = value` 修改。

**正确示例：**
```tll
let nums = [10, 20, 30]
nums[0] = 100     // ✅ Index Set for List
nums[1] = 200     // ✅
```

### 切片

v1.0 暂不支持 List 切片语法 `list[start:end]`。通过标准库函数 `arrays.slice` 实现。

## 3. Member 访问

### 定义

Member 访问使用点号语法 `obj.field`，用于访问 Map 的字段或对象的属性。field 可以是合法的标识符或关键字（关键字作为属性名时不视为关键字）。

### 语义规则

1. Member 访问的操作数必须是 Map 类型（或具有成员的对象）。
2. field 是标识符或关键字，编译器将其作为字符串键查找。
3. **关键字作为属性名**：`type`、`value`、`kind`、`struct`、`enum`、`async`、`await` 等关键字可以作为属性名使用，不视为关键字。
4. 如果字段不存在，返回 `null`（不报错）。
5. Member 访问可以链式调用：`a.b.c.d`。

**正确示例：**
```tll
let user = { name: "TLL", profile: { age: 1 } }
io.println(user.name)           // "TLL"
io.println(user.profile.age)    // 1
io.println(user.nonexistent)    // null（不报错）

// 关键字作为属性名
let node = { type: "String", value: "hello", kind: "Literal" }
io.println(node.type)    // "String"
io.println(node.value)   // "hello"
io.println(node.kind)    // "Literal"
```

**错误示例：**
```tll
let x = 42
io.println(x.name)    // Runtime Error: number has no members

let s = "hello"
io.println(s.length)  // Runtime Error: string has no members（使用 strings.length(s)）
```

## 4. Index 访问

### 定义

Index 访问使用方括号语法 `obj[index]`，用于访问 List 元素或 Map 的值。

### 语义规则

1. 对于 List：index 必须是整数，范围 `[0, length-1]`。
2. 对于 Map：index 必须是字符串，作为键查找。
3. Index 访问的表达式可以是任意表达式（不限于字面量）。

**正确示例：**
```tll
let nums = [10, 20, 30]
let i = 1
io.println(nums[i])      // 20（变量索引）

let user = { name: "TLL" }
let key = "name"
io.println(user[key])    // "TLL"（动态键）
```

**错误示例：**
```tll
let nums = [10, 20, 30]
io.println(nums["0"])    // Runtime Error: List index must be integer
```

## 5. Index Set

### 定义

Index Set 使用语法 `obj[index] = value`，用于修改 List 元素或 Map 的值。

### 语义规则

1. **List 的 Index Set 完全支持**：`list[i] = value`，i 必须是有效索引。
2. **Map 的 Index Set 在 v1.0 中不保证可用**：应使用 Member Set `map.key = value` 替代。
3. Index Set 是语句，不是表达式，不能嵌套使用。

**正确示例：**
```tll
// List Index Set — 完全支持
let nums = [1, 2, 3]
nums[0] = 100     // ✅
nums[1] = 200     // ✅

// Map 修改 — 使用 Member Set
let user = { name: "TLL" }
user.name = "New"  // ✅
```

**错误示例：**
```tll
// Map Index Set — 不保证可用
let user = { name: "TLL" }
user["name"] = "New"   // ❌ 不保证可用，使用 user.name = "New"

// 嵌套 Index Set
let nums = [1, 2, 3]
(nums[0] = 100) + 1    // ❌ Index Set 是语句，不是表达式
```

## 6. Member Set

### 定义

Member Set 使用语法 `obj.field = value`，用于修改 Map 的字段值或新增字段。

### 语义规则

1. obj 必须是 Map 类型。
2. field 是标识符，作为字符串键。
3. 如果字段已存在，覆盖其值；如果不存在，新增字段。
4. Member Set 是语句，不是表达式。
5. Member Set 支持在函数内修改外部 Map（引用语义）。

**正确示例：**
```tll
let user = { name: "TLL", age: 1 }
user.name = "TLL v1.0"   // ✅ 修改已有字段
user.email = "tll@lang.org"  // ✅ 新增字段

// 函数内修改外部 Map
fn setName(u: map, n: string) -> void {
    u.name = n    // ✅ 引用语义，修改外部对象
}
setName(user, "Updated")
io.println(user.name)   // "Updated"
```

**错误示例：**
```tll
let x = 42
x.name = "hello"    // Runtime Error: number is not a Map
```

## 7. 引用/值语义

### 定义

TLL 的数据类型分为值类型和引用类型：

| 类型 | 语义 | 说明 |
|------|------|------|
| `int` | 值 | 整数 |
| `float` | 值 | 浮点数 |
| `bool` | 值 | 布尔值 |
| `string` | 值 | 字符串（不可变） |
| `null` | 值 | 空值 |
| `list` | 引用 | 列表 |
| `map` | 引用 | 映射 |
| 函数 | 引用 | 函数对象 |

### 语义规则

1. 值类型在赋值、传参时进行拷贝，修改副本不影响原值。
2. 引用类型在赋值、传参时传递引用，修改引用指向的内容会影响所有引用。
3. 重新赋值引用变量（`a = otherList`）不会影响原引用指向的内容。

**正确示例：**
```tll
// 值类型
let a = 10
let b = a
b = 20
io.println(a)   // 10（不受影响）

// 引用类型
let list1 = [1, 2, 3]
let list2 = list1
list2[0] = 100
io.println(list1[0])   // 100（受影响，同一引用）

// 重新赋值不影响原内容
let list3 = [1, 2, 3]
let list4 = list3
list4 = [4, 5, 6]      // 重新赋值，指向新对象
io.println(list3[0])   // 1（原对象不变）
```

## 8. 参数传递

### 定义

TLL 函数参数传递遵循以下规则：
- 值类型参数：按值传递（拷贝）
- 引用类型参数：按引用传递（传递引用，但引用本身是值传递）

### 语义规则

1. 参数在函数内是局部变量，作用域限于函数体。
2. 修改值类型参数不影响调用方的变量。
3. 修改引用类型参数指向的内容（如 `list[0] = x`、`map.key = y`）会影响调用方。
4. 重新赋值参数变量（`param = other`）不影响调用方。
5. 参数数量必须与函数定义匹配（v1.0 不支持默认参数、可变参数）。

**正确示例：**
```tll
// 值类型参数 — 按值传递
fn increment(x: int) -> int {
    x = x + 1     // 修改局部拷贝
    return x
}
let n = 10
io.println(increment(n))   // 11
io.println(n)              // 10（不受影响）

// 引用类型参数 — 按引用传递
fn appendItem(lst: list, item: auto) -> void {
    arrays.push(lst, item)   // 修改原对象
}
let myList = [1, 2]
appendItem(myList, 3)
io.println(arrays.length(myList))   // 3（受影响）

// 重新赋值参数 — 不影响调用方
fn reassign(lst: list) -> void {
    lst = [9, 9, 9]   // 重新赋值局部变量
}
let original = [1, 2]
reassign(original)
io.println(original[0])   // 1（不受影响）
```

**错误示例：**
```tll
fn add(a: int, b: int) -> int { return a + b }
add(1)           // Runtime Error: too few arguments
add(1, 2, 3)     // Runtime Error: too many arguments
```

## 9. String 字面量

### 定义

TLL 支持三种字符串字面量：普通字符串、原始字符串、多行字符串。

### 普通字符串

使用双引号 `"..."`，支持转义序列。

**支持的转义序列：**

| 转义 | 含义 | Unicode |
|------|------|---------|
| `\n` | 换行 | U+000A |
| `\t` | 水平制表符 | U+0009 |
| `\r` | 回车 | U+000D |
| `\\` | 反斜杠 | U+005C |
| `\"` | 双引号 | U+0022 |
| `\0` | 空字符 | U+0000 |

**正确示例：**
```tll
let s1 = "Hello, World!"
let s2 = "Line1\nLine2\nLine3"
let s3 = "Tab\tseparated"
let s4 = "Quote: \"hello\""
let s5 = "Backslash: \\"
```

**错误示例：**
```tll
let s = "unterminated    // Parse Error: unterminated string
let s = "bad \x escape"   // Parse Error: unsupported escape sequence
```

### 原始字符串

v1.0 暂不支持原始字符串语法（如 `` `...` `` 或 `r"..."`）。如需包含大量转义字符，使用字符串拼接或标准库函数。

### 多行字符串

v1.0 中，普通字符串可以跨越多行，换行符会被包含在字符串中。

**正确示例：**
```tll
let multi = "Line 1
Line 2
Line 3"
// multi 包含换行符
```

### 字符串拼接

使用 `+` 运算符拼接字符串。字符串与其他类型拼接时，其他类型自动转换为字符串。

**正确示例：**
```tll
let name = "TLL"
let version = 1
let msg = "Welcome to " + name + " v" + version
// msg = "Welcome to TLL v1"
```

## 10. 关键字

### 定义

关键字是 TLL 语言预留的标识符，具有特殊语法含义，不能用作变量名、函数名或其他用户定义的标识符。

### 完整关键字列表

| 关键字 | 用途 |
|--------|------|
| `let` | 变量声明 |
| `const` | 常量声明 |
| `fn` | 函数声明 |
| `if` | 条件语句 |
| `else` | 条件分支 |
| `while` | while 循环 |
| `for` | for 循环 |
| `in` | for-in 循环（v1.0 部分支持） |
| `break` | 跳出循环 |
| `continue` | 跳过当前迭代 |
| `return` | 函数返回 |
| `true` | 布尔真值 |
| `false` | 布尔假值 |
| `null` | 空值 |
| `import` | 模块导入 |
| `from` | 模块来源 |
| `export` | 模块导出 |
| `as` | 别名 |
| `try` | 异常捕获开始 |
| `catch` | 异常处理 |
| `finally` | 最终执行块 |
| `throw` | 抛出异常 |
| `async` | 异步函数（v1.0 预留） |
| `await` | 等待异步结果（v1.0 预留） |
| `type` | 类型声明（v1.0 预留） |
| `struct` | 结构体（v1.0 预留） |
| `enum` | 枚举（v1.0 预留） |
| `entity` | 实体声明（AI Native） |
| `api` | API 声明（AI Native） |
| `application` | 应用声明（AI Native） |
| `agent` | Agent 声明（AI Native） |
| `tool` | Tool 声明（AI Native） |
| `workflow` | Workflow 声明（AI Native） |

### 上下文规则

1. 关键字在任何上下文中都不能用作标识符。
2. 关键字区分大小写：`Let`、`LET` 不是关键字，可用作标识符（但不推荐）。
3. `true`、`false`、`null` 是字面量关键字，代表特定值。

**错误示例：**
```tll
let let = 10        // Parse Error: 'let' is a keyword
fn fn() {}          // Parse Error: 'fn' is a keyword
let true = 1        // Parse Error: 'true' is a keyword
```

## 11. 标识符

### 定义

标识符是用户定义的名称，用于命名变量、函数、类型、模块等。

### 命名规则

1. 标识符必须以字母（a-z, A-Z）或下划线（_）开头。
2. 后续字符可以是字母、数字（0-9）或下划线。
3. 标识符区分大小写。
4. 标识符不能是关键字（见第 10 节）。
5. 标识符长度没有硬性限制，但建议不超过 255 字符。

**正确示例：**
```tll
let name = "TLL"
let _private = 42
let user_name = "admin"
let calculateTotal = 100
let _ = "unused"
```

**错误示例：**
```tll
let 123abc = 1      // Parse Error: identifier cannot start with digit
let user-name = 1   // Parse Error: '-' is not allowed in identifier
let $var = 1        // Parse Error: '$' is not allowed
let let = 1         // Parse Error: keyword
```

### 作用域

TLL 使用词法作用域（静态作用域）：

1. **全局作用域**：在所有函数外部声明的变量，全局可见。
2. **函数作用域**：函数参数和函数内声明的变量，限于函数体内可见。
3. **块级作用域**：v1.0 中，`if`/`while`/`for` 等代码块内声明的变量，其作用域规则为函数级（不支持严格块级作用域）。
4. 内层作用域可以访问外层作用域的变量。
5. 内层作用域的同名变量会遮蔽（shadow）外层变量。

**正确示例：**
```tll
let globalVar = 100    // 全局作用域

fn test() -> void {
    let localVar = 200  // 函数作用域
    io.println(globalVar)   // 100（访问全局）
    io.println(localVar)    // 200
    
    if true {
        let blockVar = 300  // 块级（函数级作用域）
        io.println(blockVar)  // 300
    }
    // v1.0 中 blockVar 在此处可能仍可见（函数级作用域）
}
```

## 12. 赋值运算符

### 定义

TLL 支持以下赋值运算符：

| 运算符 | 含义 | 等价于 |
|--------|------|--------|
| `=` | 简单赋值 | — |
| `+=` | 加法赋值 | `a = a + b` |
| `-=` | 减法赋值 | `a = a - b` |
| `*=` | 乘法赋值 | `a = a * b` |
| `/=` | 除法赋值 | `a = a / b` |
| `%=` | 取模赋值 | `a = a % b` |

### 语义规则

1. 赋值运算符的左操作数必须是可赋值的（变量、List 索引、Map 成员）。
2. 复合赋值运算符（`+=` 等）先读取左操作数的当前值，执行运算，再写回。
3. 赋值是语句，不是表达式，不能嵌套使用。
4. 不支持链式赋值（`a = b = c`）。

**正确示例：**
```tll
let x = 10
x += 5     // x = 15
x -= 3     // x = 12
x *= 2     // x = 24
x /= 4     // x = 6
x %= 4     // x = 2

// List 元素复合赋值
let nums = [10, 20]
nums[0] += 5    // nums[0] = 15

// Map 字段复合赋值
let stats = { count: 0 }
stats.count += 1   // stats.count = 1
```

**错误示例：**
```tll
let x = 10
let y = x += 5    // Parse Error: assignment is statement, not expression
a = b = c = 1     // Parse Error: chained assignment not supported
5 += 3             // Parse Error: left operand must be assignable
```

## 13. 函数

### 定义

函数是 TLL 的基本代码组织单元，封装可重用的逻辑。

### 函数定义

语法：
```
fn name(param1: type1, param2: type2, ...) -> returnType {
    // body
}
```

### 语义规则

1. 函数名必须是合法标识符，不能是关键字。
2. 参数列表可以为空。
3. 每个参数必须指定类型（v1.0 中类型标注是语法要求，但类型检查器可推断）。
4. 返回类型可以省略，默认为 `void`。
5. 函数体是一个代码块。
6. `return` 语句用于返回值；无 `return` 时，函数返回 `null`（void 函数）。
7. 函数是一等公民，可以赋值给变量、作为参数传递、作为返回值。
8. 函数定义可以嵌套（内部函数）。

**正确示例：**
```tll
// 简单函数
fn add(a: int, b: int) -> int {
    return a + b
}

// 无参数、无返回值
fn greet() -> void {
    io.println("Hello!")
}

// 省略返回类型（默认为 void）
fn log(msg: string) {
    io.println(msg)
}

// 函数作为值
fn multiply(a: int, b: int) -> int { return a * b }
let op = multiply
io.println(op(3, 4))   // 12

// 嵌套函数
fn outer() -> int {
    fn inner(x: int) -> int { return x * 2 }
    return inner(21)
}
io.println(outer())   // 42
```

### 函数调用

语法：`name(arg1, arg2, ...)`

1. 参数数量必须与函数定义匹配。
2. 参数按位置传递（v1.0 不支持关键字参数）。
3. 函数调用是表达式，可以嵌套。

**正确示例：**
```tll
let result = add(3, 4)           // 7
let nested = add(add(1, 2), 3)   // 6
```

**错误示例：**
```tll
add(1)           // Runtime Error: too few arguments
add(1, 2, 3)     // Runtime Error: too many arguments
```

## 14. 闭包

### 定义

闭包是捕获了外部作用域变量的函数。内部函数可以访问并修改外部函数的局部变量。

### 语义规则

1. 内部函数可以访问外部函数的局部变量和参数。
2. 内部函数可以修改外部变量（通过 Member Set 修改引用类型内容；v1.0 中修改标量外部变量的能力已通过全局变量机制支持）。
3. 闭包捕获的是变量的引用，不是值的拷贝。
4. 闭包可以在外部函数返回后继续存在，并保持对捕获变量的访问。

**正确示例：**
```tll
// 闭包捕获外部变量
fn makeCounter() -> fn {
    let count = 0
    fn counter() -> int {
        count = count + 1
        return count
    }
    return counter
}

let c = makeCounter()
io.println(c())   // 1
io.println(c())   // 2
io.println(c())   // 3

// 闭包捕获参数
fn makeAdder(x: int) -> fn {
    fn adder(y: int) -> int {
        return x + y
    }
    return adder
}

let add5 = makeAdder(5)
io.println(add5(3))   // 8
io.println(add5(10))  // 15
```

## 15. 递归

### 定义

递归是函数直接或间接调用自身的编程技术。

### 语义规则

1. 函数可以直接调用自身（直接递归）。
2. 函数 A 可以调用函数 B，函数 B 再调用函数 A（间接递归）。
3. 每次递归调用创建新的栈帧，包含独立的参数和局部变量。
4. 递归必须有终止条件（base case），否则会导致栈溢出。
5. v1.0 不保证尾递归优化（TCO）。深度递归可能导致栈溢出。
6. 调用栈深度受运行时限制，建议递归深度不超过 10000 层。

**正确示例：**
```tll
// 阶乘（直接递归）
fn factorial(n: int) -> int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}
io.println(factorial(5))   // 120

// 斐波那契（直接递归）
fn fib(n: int) -> int {
    if n <= 1 {
        return n
    }
    return fib(n - 1) + fib(n - 2)
}
io.println(fib(10))   // 55

// 间接递归
fn isEven(n: int) -> bool {
    if n == 0 { return true }
    return isOdd(n - 1)
}
fn isOdd(n: int) -> bool {
    if n == 0 { return false }
    return isEven(n - 1)
}
io.println(isEven(4))   // true
io.println(isOdd(7))    // true
```

**错误示例：**
```tll
// 无限递归（无终止条件）
fn infinite() -> void {
    infinite()    // Runtime Error: stack overflow
}
```

## 16. 模块

### 定义

模块是 TLL 的代码组织单元，每个 `.tll` 文件是一个模块。模块通过 `import`/`export` 共享符号。

### export

使用 `export` 关键字导出函数、变量等符号。

**正确示例：**
```tll
// math.tll
export fn add(a: int, b: int) -> int {
    return a + b
}

export fn multiply(a: int, b: int) -> int {
    return a * b
}

export const PI = 3.14159
```

### import

使用 `from "module" import symbol1, symbol2` 语法导入符号。

**正确示例：**
```tll
// main.tll
from "math" import add, multiply, PI

io.println(add(3, 4))        // 7
io.println(multiply(3, 4))   // 12
io.println(PI)                // 3.14159
```

### 语义规则

1. 模块路径是相对于当前文件的路径，省略 `.tll` 扩展名。
2. 标准库模块（如 `io`、`json`、`math`）不需要路径，直接按名称导入。
3. 未导出的符号是模块私有的，不能被其他模块导入。
4. 导入的符号在当前模块作用域内可用。
5. 循环导入在 v1.0 中不保证支持，应避免。
6. 模块只加载一次，多次导入同一模块返回相同的模块实例。

**错误示例：**
```tll
// 导入不存在的符号
from "math" import nonexistent   // Runtime Error: symbol not found

// 导入未导出的符号
// math.tll 中有 fn privateFn() {}（未 export）
from "math" import privateFn     // Runtime Error: symbol not exported
```

## 17. 异常

### 定义

异常是 TLL 的错误处理机制，通过 `throw` 抛出异常，通过 `try`/`catch`/`finally` 捕获和处理异常。

### throw

使用 `throw` 语句抛出异常。异常值可以是任意类型（通常是字符串）。

**正确示例：**
```tll
fn divide(a: int, b: int) -> float {
    if b == 0 {
        throw "Division by zero"
    }
    return a / b
}
```

### try/catch/finally

语法：
```
try {
    // 可能抛出异常的代码
} catch err {
    // 异常处理
} finally {
    // 无论是否异常都执行的清理代码
}
```

### 语义规则

1. `try` 块包含可能抛出异常的代码。
2. `catch` 块在异常发生时执行，`err` 是捕获的异常值。
3. `finally` 块无论是否发生异常都会执行，用于资源清理。
4. `catch` 和 `finally` 至少要有一个，可以只有 `try`/`finally`（不捕获异常但执行清理）。
5. 异常会沿调用栈向上传播，直到被捕获。如果未被捕获，程序终止并打印错误信息。
6. 标准库函数的错误可以被 `try`/`catch` 捕获。

**正确示例：**
```tll
// 基本异常处理
try {
    let result = divide(10, 0)
    io.println(result)
} catch err {
    io.println("Error: " + err)   // "Error: Division by zero"
}

// finally 块
let file = null
try {
    file = fs.open("data.txt")
    let content = fs.readFile(file)
    io.println(content)
} catch err {
    io.println("Failed: " + err)
} finally {
    if file != null {
        fs.close(file)   // 总是执行
    }
}

// 异常传播
fn level1() -> void {
    throw "Error from level1"
}
fn level2() -> void {
    level1()   // 异常向上传播
}
try {
    level2()
} catch err {
    io.println("Caught: " + err)   // "Caught: Error from level1"
}
```

**错误示例：**
```tll
// 未捕获的异常导致程序终止
fn bad() -> void {
    throw "Uncaught error"
}
bad()   // Program terminates with error message
```

## 18. null 的类型和语义

### 定义

`null` 是 TLL 的特殊值，表示"无值"或"空引用"。`null` 是关键字，也是字面量。

### 语义规则

1. `null` 是 `null` 类型的唯一值。
2. 任何类型的变量都可以赋值为 `null`（v1.0 中类型系统不严格区分可空/非空）。
3. 访问 `null` 的成员或索引会导致运行时错误。
4. `null` 与任何值比较：`null == null` 为 `true`，`null == other` 为 `false`。
5. 函数未显式 `return` 时，返回 `null`。
6. Map 中不存在的字段返回 `null`（不报错）。
7. `null` 在布尔上下文中为 `false`。

**正确示例：**
```tll
let x = null
io.println(x == null)   // true

// 函数返回 null
fn noReturn() {
    // 无 return 语句
}
io.println(noReturn() == null)   // true

// Map 不存在的字段返回 null
let user = { name: "TLL" }
io.println(user.age == null)   // true

// null 的布尔值
if null {
    io.println("never")   // 不执行
}

// 安全访问模式
let value = user.age
if value != null {
    io.println("Age: " + value)
} else {
    io.println("Age not set")
}
```

**错误示例：**
```tll
let x = null
io.println(x.name)    // Runtime Error: cannot access member of null
io.println(x[0])      // Runtime Error: cannot index null
```

## 19. 内置函数

### 定义

内置函数是 TLL 运行时提供的标准库函数，无需导入即可使用（部分模块需要显式导入）。

### 全局内置函数

以下函数在全局作用域可用，无需导入：

| 函数 | 说明 |
|------|------|
| `io.println(...)` | 打印并换行 |
| `io.print(...)` | 打印不换行 |
| `io.readLine()` | 读取一行输入 |

### 标准库模块

以下模块需要通过 `from "module" import ...` 导入：

| 模块 | 主要函数 |
|------|----------|
| `json` | `parse`, `stringify` |
| `math` | `sqrt`, `abs`, `pow`, `floor`, `ceil`, `round`, `min`, `max`, `random`, `pi`, `e` 等 |
| `strings` | `length`, `charAt`, `substring`, `indexOf`, `toUpperCase`, `toLowerCase`, `trim`, `split`, `replace`, `startsWith`, `endsWith`, `contains` 等 |
| `arrays` | `length`, `push`, `pop`, `get`, `set`, `contains`, `indexOf`, `map`, `filter`, `reduce`, `sort`, `reverse`, `join`, `slice` 等 |
| `convert` | `toInt`, `toFloat`, `toBool`, `toString`, `typeOf` |
| `fs` | `readFile`, `writeFile`, `appendFile`, `exists`, `mkdir`, `remove`, `listDir`, `copyFile` 等 |
| `http` | `get`, `getText`, `post`, `postJson` 等 |
| `agent` | `run`, `chat`, `setApiKey`, `setBaseUrl`, `setModel`, `runWithTools`, `saveMemory`, `loadMemory` 等 |
| `workflow` | `start`, `trigger`, `getState`, `getHistory` 等 |

### 扩展方式

1. 自定义函数：通过 `fn` 定义函数，可以放在模块中导出。
2. 自定义模块：创建 `.tll` 文件，通过 `export` 导出符号，其他模块通过 `import` 使用。
3. 内置函数扩展：v1.0 中，新增内置函数需要修改运行时（Bootstrap 阶段修改 TypeScript 运行时；自举后修改 TLL 运行时）。

**正确示例：**
```tll
// 使用标准库
from "math" import sqrt, pow
from "strings" import toUpperCase, length
from "arrays" import map, filter, reduce

io.println(sqrt(16))           // 4
io.println(pow(2, 10))         // 1024
io.println(toUpperCase("tll"))  // "TLL"

let nums = [1, 2, 3, 4, 5]
let doubled = map(nums, fn(x) { return x * 2 })
let evens = filter(nums, fn(x) { return x % 2 == 0 })
let sum = reduce(nums, 0, fn(acc, x) { return acc + x })
```

## 20. 自举契约

### 定义

自举（Self-hosting）是指用 TLL 语言自身编写 TLL 编译器。自举契约规定了编译器自举必须满足的语义要求和验证标准。

### 自举架构

```
TLL Source Code
    │
    ▼
TLL Compiler (written in TLL)
    │
    ▼
TLL Bytecode
    │
    ▼
TLL Runtime (VM)
    │
    ▼
Execution Result
```

### 自举阶段

| 阶段 | 编译器实现 | 说明 |
|------|-----------|------|
| Bootstrap | TypeScript | 第一代编译器，用于编译 TLL 编写的编译器 |
| Self-hosted | TLL | 用 TLL 重写的编译器，由 Bootstrap 编译器编译 |
| Self-hosted² | TLL | 用自举编译器编译自身，验证自举完整性 |

### 语义要求

1. **确定性编译**：同一 TLL 源程序，无论由 Bootstrap 编译器还是自举编译器编译，必须产生完全一致的字节码。
2. **语义等价**：自举编译器编译的程序，其运行时行为必须与 Bootstrap 编译器编译的程序完全一致。
3. **完整覆盖**：自举编译器必须支持本规范定义的所有语义特性，不得有遗漏或简化。
4. **错误处理一致**：编译错误、运行时错误的报告方式和错误信息必须一致。

### 验证标准

自举验证通过以下三步确认：

1. **字节码 A**：使用 Bootstrap 编译器（TypeScript）编译 TLL 编写的 TLL 编译器源程序，产生字节码 A。
2. **字节码 B**：使用字节码 A（在 TLL Runtime 上运行）编译同一 TLL 编译器源程序，产生字节码 B。
3. **比对**：字节码 A 与字节码 B 必须完全一致（逐字节相同）。

```
Bootstrap Compiler (TypeScript)
    │ compile TLL Compiler source
    ▼
Bytecode A
    │ run on TLL VM, compile same TLL Compiler source
    ▼
Bytecode B
    │ compare
    ▼
A == B  →  Self-hosting verified ✅
A != B  →  Semantic divergence detected ❌
```

### 不通过的处理

如果字节码 A 与字节码 B 不一致，说明存在语义分歧：

1. 定位分歧点：对比两份字节码，找到第一条不同的指令。
2. 追溯原因：分析该指令对应的源程序位置，确定是 Bootstrap 编译器还是自举编译器的实现不符合规范。
3. 修正实现：根据本规范修正不符合的实现。
4. 重新验证：重复三步验证，直到 A == B。

### 自举后的维护

自举成功后：

1. TypeScript Bootstrap 编译器进入维护模式，仅用于紧急修复和兼容性验证。
2. TLL 编译器的后续开发由 TLL 编写的编译器自身完成。
3. 每次编译器更新后，必须重新执行自举验证，确保语义一致性。
4. 本规范（v1.0-semantic-freeze）在 v1.0 生命周期内不得修改。如需新增语义特性，需在 v1.1 或更高版本中定义。
