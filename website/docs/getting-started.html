🚀 入门指南

5 分钟上手 TLL 编程语言。本指南将带你完成环境配置、编写第一个程序、了解项目结构。

1. 安装

TLL 目前处于 Bootstrap 阶段，编译器由 TypeScript 实现。需要 Node.js 18+ 环境。

从源码安装

# 克隆仓库
git clone https://github.com/aliquanhou/tll.git
cd tll/tll-compiler

# 安装依赖
npm install

# 编译 TypeScript
npx tsc

# 验证安装
node dist/src/cli.js --version
# tll version 0.1.0-bootstrap

创建别名（可选）

# Linux / macOS
echo 'alias tll="node /path/to/tll/tll-compiler/dist/src/cli.js"' >> ~/.bashrc
source ~/.bashrc

# 验证
tll --version

2. Hello World

创建你的第一个 TLL 程序：

# hello.tll
fn main() {
    io.println("Hello, TLL World!")

    let name = "TLL"
    let version = "0.1"
    io.println("Language: " + name + " v" + version)
}

main()

运行程序：

tll run hello.tll
# Hello, TLL World!
# Language: TLL v0.1

3. 项目结构

一个标准的 TLL 项目结构：

myapp/
├── tll.toml          # 包清单
├── src/
│   ├── main.tll      # 入口文件
│   ├── utils.tll     # 工具模块
│   └── models/
│       ├── user.tll
│       └── product.tll
├── tests/
│   └── main_test.tll
└── docs/
    └── README.md

tll.toml 包清单

[package]
name = "myapp"
version = "0.1.0"
license = "MIT"
authors = ["Your Name "]

[dependencies]
http = "1.0.0"
json = "2.1.0"

4. CLI 命令参考

命令说明
tll new <name>创建新项目
tll run <file>编译并运行
tll build <file>编译为字节码 (.tllbc)
tll check <file>仅类型检查，不生成代码
tll lex <file>输出 Token 流
tll parse <file>输出 AST（JSON 格式）
tll test运行测试
tll fmt格式化代码
tll add <pkg>添加依赖
tll --version显示版本
