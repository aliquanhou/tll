# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.1.x   | ✅ Yes |
| < 1.1   | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability in TLL OS, please report it responsibly:

1. **Do NOT** open a public GitHub issue
2. Report via GitHub Security Advisory or email the maintainers
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Affected versions
   - Potential impact
   - Any suggested fix

## Response Timeline

- Initial response: within 72 hours
- Assessment and triage: within 7 days
- Fix and release: depending on severity

## What We Expect

- Researchers act in good faith
- No exploitation of vulnerabilities beyond proof-of-concept
- No access to or modification of other users' data
- Clear communication of findings

## What We Promise

- Acknowledge reports promptly
- Keep researchers informed of progress
- Credit researchers in release notes (with permission)
- Not pursue legal action for good-faith research

## Scope

This policy covers:
- TLL OS compiler and runtime
- TLL OS CLI tools
- TLL OS standard library

Out of scope:
- Third-party dependencies (report to upstream)
- Documentation typos (open a PR)
